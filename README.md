# Stem — instaladores

Stem es un agente para Ableton Live: le pedís cosas en el chat y las hace en tu sesión.

Acá están solo los instaladores para macOS (el código no es público). Bajá el último en
[Releases](../../releases/latest):

- **Apple M1, M2, M3, M4…** → `Stem-<versión>-arm64.dmg`
- **Intel** → `Stem-<versión>-x64.dmg`

La primera vez macOS la bloquea porque todavía no está firmada por Apple: Ajustes del Sistema →
Privacidad y seguridad → **Abrir igualmente**. Stem avisa solo cuando hay una versión nueva.
